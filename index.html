💡 Vì sao chỉnh sửa trên máy tính mà Vercel chưa cập nhật?

Khi bạn sửa bàn hoặc thêm khách qua giao diện web, dữ liệu được lưu trong bộ nhớ riêng (LocalStorage) của trình duyệt trên máy tính đó. Để Vercel và điện thoại hiển thị đúng, bạn có thể chọn 1 trong 2 cách đơn giản dưới đây:

Cách 1: Xuất / Nhập File Dữ Liệu (Không cần đụng code) Khuyên dùng

1. Bấm "📥 Tải File Dữ Liệu" trên máy tính đang có danh sách chuẩn.
2. Mở link trang web trên Vercel (hoặc trên điện thoại), vào mục này và bấm "📤 Nhập File Dữ Liệu" là toàn bộ sơ đồ sẽ đồng bộ 100%!

Cách 2: Đồng bộ vào mã nguồn để Commit lên GitHub Tự động cho tất cả mọi người

1. Bấm nút "📋 Sao Chép Mã allTablesData" bên dưới.
2. Mở file index.html trong VS Code, tìm đoạn const allTablesData = [ ... ]; và Paste đè lên.
3. Commit & Push lên GitHub. Khi đó Vercel sẽ tự động có dữ liệu này làm mặc định gốc cho mọi thiết bị!
